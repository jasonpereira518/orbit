# Mobile UX review branch

Branch: `codex/mobile-ux-improvements`

This branch implements the concrete mobile workflow improvements from the November 9 mobile audit. It does not introduce database migrations, new AI providers, automatic sends, or an offline sync system.

## What to review

- Home puts reminders and due follow-ups ahead of statistics and charts. Existing meeting, Radar, approval and setup sections remain available. The task-first section order also applies on desktop.
- Contact rows expose Follow up, Log interaction, Reminders, LinkedIn and the existing confirmed deletion flow through a mobile action menu.
- Manual contact creation requires only a name on phones. Optional details expand in place, invalid hidden fields reveal themselves, and Save stays anchored in the form. Desktop retains the full form.
- New-entry drafts recover within the same tab and account, expire after 24 hours and clear after successful creation. Explicit relationship ratings survive recovery; default ratings remain unrated. Existing profile edits do not restore over current server data.
- Profiles use a smaller mobile identity block, wrap secondary controls, and offer a persistent Log / Follow up action row above the bottom navigation.
- Contacts has one mobile Filters sheet with draft selections, Apply, Reset, selected-filter count and URL navigation that preserves scroll. Import scope survives normal filtering and Reset; Reset clears tag/letter scopes.
- Capture shows Notes and Voice first, with a More sources menu. Every existing source remains available, including a selected secondary tab. Arrow/Home/End navigation works across visible enabled tabs.
- More groups destinations into Act, Explore and Manage, includes Settings, scrolls within short viewports, and retains surface gating and tier tags. Tab visuals shrink to their allocated width on small phones.
- Long edit, interaction and follow-up sheets use the whole phone viewport with a shared sticky task header and reachable Close control. Email composition has a full-height phone view. Follow-up actions stay anchored and use larger touch spacing.
- Constellation contact details open as a bottom preview on phones with an explicit expand action. Desktop keeps its side panel. Search copy is shorter. Edge labels truncate inside the canvas without moving their interactive anchors. Existing camera, renderer, gestures and graph information remain intact.
- Reminders has an explicit mobile selection mode, room for two-line titles and a wrapping bulk toolbar.
- Radar's secondary rationale expands on demand on phones; dismissal remains accessible through More. Campaign prospect details and draft controls expand per person instead of occupying every row at once.
- Settings has a mobile section chooser and sufficient anchor offset. AI setup has a direct button and a same-origin return link back to the original task, including query context. Existing capture draft recovery covers the notes detour.
- Unsupported meeting-recording browsers lead with usable note/upload alternatives. Existing microphone recording remains available where supported.
- Event attendee bulk actions sit above the mobile nav. Knowledge omits summaries that merely repeat the same role/company sentence.
- Find starts with description-based discovery, keeps person/company research available and wraps its controls on narrow screens. Quick setup appears first on phones while desktop retains the guided-tour visual priority. Terms acceptance is unchanged.
- The mobile landing hero has a shorter scroll-pinned sequence. Pricing compares the effective plan rules vertically on phones, retaining the full table on larger screens.
- Shared phone inputs and coarse-pointer menu rows have larger physical targets.

## Validation

- TypeScript: passed for the completed implementation.
- ESLint on changed TypeScript/TSX: no errors. Five existing `react-hooks/set-state-in-effect` warnings in unchanged code within touched files.
- New contact draft tests cover account/context isolation, actual restoration including the user's rating, expiry, malformed/wrong-type input, unavailable storage and clearing empty drafts.
- Graph canvas smoke checks pass, including camera math, hit testing, pinch, inertia, renderer breakpoints and large-network indexing.
- Relevant tap-target, corner-clearance, accessibility-pattern, onboarding-copy, AI-notice-copy and double-render smoke checks pass.
- Smoke manifest structural check passes. The new draft test is registered as a pure smoke suite.
- Tailwind compiles the responsive task-sheet positioning and coarse-pointer utilities.
- Production build was attempted. It fails while fetching existing Fraunces/Outfit fonts from `fonts.googleapis.com` because DNS/network access is unavailable here. No fonts or network policy were changed to hide that failure.
- A separate preview server could not start because the execution environment denies opening a listening port. Browser/E2E and physical-device visual QA have not been completed for this branch.

## Review on devices before merging

At 320/360/390/430px, tablet width and landscape, check contact filters, name-only creation, restoring a partially completed contact, hidden invalid fields, long task Close/Save access, More scrolling, graph preview/expand/reset, reminder selection and campaign review. Verify iOS Safari and Android Chrome with the keyboard open, dark mode, 200% text and VoiceOver/TalkBack. Confirm no viewport overflow or overlapping touch targets and compare the affected desktop flows.

Use a demo account for capture/AI/send checks. Review recipient, channel and existing final-send controls without sending a real message. Do not treat source/type checks as evidence that real-device gestures or layout have passed.

This branch was created from its committed HEAD in an isolated clone because the original checkout's Git metadata was read-only to the agent. The deliverable Git bundle carries only this branch's commit above that base and can be fetched into the original repository for review.
